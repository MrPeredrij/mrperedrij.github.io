# Справочник по языку C

Статический сайт-справочник по языку C (C11/C17) — индивидуальный проект (тема 1) к лабораторной работе 2.1
«Настройка CDN для статического веб-сайта». Размещается на GitHub Pages и проксируется через Cloudflare.

- 15 HTML-страниц с общей навигацией и одной таблицей стилей `style.css`;
- `image.jpg` — баннер на главной странице;
- `assets/js/prism.js` — локальный подсветчик синтаксиса Prism 1.29 (C, Bash), лицензия MIT;
- `assets/fonts/*.woff2` — локальный шрифт JetBrains Mono (SIL OFL 1.1);
- внешних CDN-зависимостей нет: все ресурсы отдаются с Origin.

Для CDN: HTML — много однотипных страниц (Cache Hit Ratio), `style.css`, `assets/js`, `assets/fonts` — кандидаты на долгий TTL.
Все примеры кода компилируются `gcc -std=c17 -Wall -Wextra -pedantic` без предупреждений.

# Записки embedded-разработчика

Статический сайт «Записки embedded-разработчика»: записки и справочник для embedded-разработчика
по языку C (C11/C17) и C++17, базовым алгоритмам и программированию микроконтроллеров.
Мини-проект. Размещается на GitHub Pages и проксируется через Cloudflare.

- главная страница — хаб из четырёх тем: C, C++, общие темы (алгоритмы и FAQ), микроконтроллеры;
- HTML-страницы с общей сворачиваемой навигацией и одной таблицей стилей `style.css`;
- раздел C++17 пока без STL (он планируется позже), раздел микроконтроллеров — заглушка (WIP);
- `image.jpg` — баннер на главной странице;
- `CNAME` — пользовательский домен `mrperedrij.dpdns.org`;
- `assets/js/prism.js` — локальный подсветчик синтаксиса Prism 1.29 (C, C++, Bash), лицензия MIT;
- `assets/fonts/*.woff2` — локальный шрифт JetBrains Mono (SIL OFL 1.1);
- внешних CDN-зависимостей нет: все ресурсы отдаются с Origin.

Для CDN: HTML — много однотипных страниц (Cache Hit Ratio), `style.css`, `assets/js`, `assets/fonts` — кандидаты на долгий TTL.
Примеры на C компилируются `gcc -std=c17 -Wall -Wextra -pedantic` без предупреждений,
примеры на C++ — `g++ -std=c++17 -Wall -Wextra -pedantic`.

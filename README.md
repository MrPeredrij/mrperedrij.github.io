# Справочник по языку C

Статический сайт-справочник по языку C (C11/C17) и C++17 — индивидуальный проект (тема 1) к лабораторной работе 2.1
«Настройка CDN для статического веб-сайта». Размещается на GitHub Pages и проксируется через Cloudflare.

- HTML-страницы с общей навигацией и одной таблицей стилей `style.css`;
- разделы по языку C, введению в C++17 (без STL — этот раздел планируется позже), базовым алгоритмам
  и заглушка «Программирование микроконтроллеров» (WIP);
- `image.jpg` — баннер на главной странице;
- `CNAME` — пользовательский домен `mrperedrij.dpdns.org`;
- `assets/js/prism.js` — локальный подсветчик синтаксиса Prism 1.29 (C, C++, Bash), лицензия MIT;
- `assets/fonts/*.woff2` — локальный шрифт JetBrains Mono (SIL OFL 1.1);
- внешних CDN-зависимостей нет: все ресурсы отдаются с Origin.

Для CDN: HTML — много однотипных страниц (Cache Hit Ratio), `style.css`, `assets/js`, `assets/fonts` — кандидаты на долгий TTL.
Примеры на C компилируются `gcc -std=c17 -Wall -Wextra -pedantic` без предупреждений,
примеры на C++ — `g++ -std=c++17 -Wall -Wextra -pedantic`.

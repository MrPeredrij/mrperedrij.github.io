Установка и компиляция

Программа на C — это текстовые файлы с исходным кодом (.c) и заголовками (.h). Компилятор превращает их в исполняемый файл. Сборка проходит четыре стадии:

  1. Препроцессирование — подстановка #include и макросов (gcc -E).
  2. Компиляция — перевод в ассемблер (gcc -S).
  3. Ассемблирование — получение объектного файла .o (gcc -c).
  4. Компоновка — объединение объектных файлов и библиотек в программу.

Программа из нескольких файлов

Объявления выносят в заголовок, определения — в .c-файл. Защита от повторного включения (include guard) не даёт заголовку подключиться дважды.

Минимальный Makefile

Строки с командами в Makefile должны начинаться с символа табуляции.

Функция main возвращает код завершения: 0 (или EXIT_SUCCESS) означает успех. Начиная с C99 при выходе из main без return автоматически возвращается 0.

Целые типы фиксированного размера

Заголовок <stdint.h> (C99) даёт типы с точно известной шириной, а <inttypes.h> — макросы форматов для них. <stdbool.h> определяет bool, true и false.

Литералы

  • Целые: 42, 052 (восьмеричный), 0x2A (шестнадцатеричный); суффиксы u, l, ll: 42ul.
  • Вещественные: 3.14 (double), 3.14f (float), 1e-9, 0x1.8p1 (= 3.0).
  • Символьные: 'A', '\n', '\0', '\x41'. Тип символьного литерала в C — int.
  • Строковые: "текст" — массив char с завершающим '\0'.

Преобразования типов

В выражениях действуют обычные арифметические преобразования: типы меньше int повышаются до int, затем операнды приводятся к общему типу. Смешивание знаковых и беззнаковых целых — частый источник ошибок: при сравнении -1 < 1u значение -1 превращается в UINT_MAX, и результат оказывается ложным.

Переполнение знакового целого — неопределённое поведение. Беззнаковые типы при переполнении «заворачиваются» по модулю 2N, это определено стандартом.

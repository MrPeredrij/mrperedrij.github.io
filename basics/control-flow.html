Управление потоком выполнения

if и else

Условие — любое скалярное выражение: ноль означает «ложь», всё остальное — «истину».

switch

Метки case должны быть целочисленными константными выражениями. Без break выполнение «проваливается» в следующую ветку.

Циклы

ЦиклКогда проверяется условие
while (усл) телоперед каждой итерацией
do тело while (усл);после итерации — тело выполнится хотя бы раз
for (иниц; усл; шаг) телоперед каждой итерацией; переменная из иниц видна только в цикле (C99)

goto

goto редко нужен, но в C это признанный способ централизованно освобождать ресурсы при ошибках:

Частая ошибка — if (x = 5) вместо if (x == 5). Флаг -Wall предупреждает о таком присваивании в условии.

Пространства имён

Пространство имён группирует имена, чтобы они не сталкивались в глобальной области. Стандартная библиотека C++ живёт в std: отсюда std::printf и std::cout.

Директива и объявление using

using math::abs_int; вводит одно имя в текущую область. using namespace math; вводит все имена пространства. Второе удобно в коротком .cpp, но в заголовках его избегают: подключивший заголовок внезапно получит десятки имён и риск неоднозначности.

Анонимное пространство имён

Безымянный namespace { ... } даёт внутреннюю компоновку: имена видны только в этой единице трансляции. В C для той же цели используют static на функциях и переменных уровня файла.

Разрешение имён

  • ::name — искать в глобальной области, минуя одноимённые локальные объявления.
  • ns::name — квалифицированное имя.
  • Пространство можно дописать позже: несколько блоков namespace math { ... } объединяются.
Аргумент-зависимое связывание (ADL): для std::cout << x компилятор ищет operator<< в том числе в пространстве типа x. Поэтому перегрузку вывода обычно кладут в то же пространство, что и сам тип.

new и delete

Оператор new выделяет память и вызывает конструктор. delete вызывает деструктор и освобождает память. Для массивов используют пару new[] / delete[] — смешивать с обычными new / delete нельзя.

Сравнение с malloc и free

malloc / freenew / delete
ЯзыкC (доступны и в C++)Только C++
Конструктор / деструкторне вызываютсявызываются
Тип результатаvoid *, в C++ нужно приведениеуказатель нужного типа
Ошибка выделениявозвращает NULLпо умолчанию бросает исключение std::bad_alloc
Память, выделенную new, освобождают только delete. Память от malloc — только free. Смешивать нельзя.

Типичные ошибки

  • Забыть delete — утечка памяти. Для массива забыть скобки: delete p; вместо delete[] p;.
  • Дважды вызвать delete для одного адреса — неопределённое поведение. После удаления полезно присвоить nullptr; повторный delete nullptr; безопасен и ничего не делает.
  • Использовать объект после delete (висячий указатель).
  • Выделить через new в одной функции и надеяться, что другая «когда-нибудь» освободит — легко потерять владение, особенно при раннем return или исключении.
Надёжнее не разбрасывать голые new/delete по коду, а прятать ресурс в класс (RAII: ресурс захватывается в конструкторе и освобождается в деструкторе). Тогда исключение или ранний return не приведут к утечке. Готовые обёртки есть в стандартной библиотеке (std::unique_ptr) — они относятся к STL и будут разобраны позже.

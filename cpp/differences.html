Отличия C++ от C

C++ вырос из C и до сих пор может использовать большую часть его синтаксиса и библиотеки (<cstdio>, <cstring> и т. д.). Это не строгий суперсет: некоторые конструкции C в C++ недопустимы, а ряд имён в C++ — ключевые слова.

Первая программа

В C++ принято писать ввод-вывод через <iostream>, хотя printf по-прежнему доступен. Функция main может быть записана как int main() — в C++ пустые скобки означают «параметров нет», в отличие от C17, где для этого нужно (void).

Типы и литералы

  • bool — полноценный тип со значениями true и false (в C для этого есть _Bool и <stdbool.h>).
  • nullptr (C++11) — нулевой указатель. Предпочтительнее, чем NULL или 0.
  • Символьные типы char16_t, char32_t, с C++20 ещё char8_t.
  • Ссылки T& и const T& — отдельных типов-ссылок в C нет.

Более строгая проверка типов

C++ не позволяет неявно преобразовать void * к другому указателю — в C это обычная практика с malloc. Функция без параметров записывается f() или f(void) одинаково. Несколько объявлений одной функции с разными параметрами — это уже перегрузка, а не «старый стиль» C.

Компоновка с C—extern "C" отключает декорирование имён
Обёртка extern "C" нужна, когда заголовок подключают и из C, и из C++: компилятор C++ иначе «украшает» имена функций (name mangling), и компоновщик не найдёт символ, собранный компилятором C.
Компилируйте C как C, а C++ как C++. Файл с классами, ссылками или new нельзя собрать командой gcc -std=c17.

Наследование и полиморфизм

Наследование строит новый класс на основе существующего. При class Derived : public Base открытый интерфейс базы остаётся открытым в наследнике: «Derived является Base». Это основной вид наследования для полиморфизма.

Виртуальные функции

Если метод объявлен как virtual, вызов через указатель или ссылку на базовый тип выбирает версию фактического объекта. Это и есть полиморфизм во время выполнения. В C++11 в наследнике пишут override: компилятор проверит, что в базе есть такая же виртуальная функция.

Чисто виртуальные функции и абстрактные классы

Объявление virtual double area() const = 0; делает функцию чисто виртуальной, а класс — абстрактным: создать объект Shape нельзя, можно только наследовать и реализовать недостающие методы. Абстрактный класс удобен как общий интерфейс.

Виртуальный деструктор

Если объект производного класса удаляют через указатель на базу (delete base;), деструктор базы должен быть виртуальным. Иначе вызовется только деструктор базы, и часть ресурса наследника утечёт.

Присваивание производного объекта в переменную базового типа срезает объект (object slicing): остаются только поля базы. Для полиморфизма передавайте указатель или ссылку.
final на классе или методе запрещает дальнейшее наследование или переопределение. protected в базе полезен для методов и полей, которыми пользуется только иерархия, но не внешний код.

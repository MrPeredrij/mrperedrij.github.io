Исключения

Исключение — способ сообщить об ошибке, не заворачивая каждый вызов в проверку кода возврата. Оператор throw создаёт исключение. Блок try защищает участок кода, catch перехватывает объект подходящего типа. Если подходящего catch нет, программа завершается.

Раскрутка стека

При throw C++ уничтожает автоматические объекты в уже начатых блоках (вызывает деструкторы) пока не найдёт подходящий catch. Это раскрутка стека (stack unwinding). Поэтому ресурсы, захваченные в объекте с деструктором, освободятся сами. Голый new без владельца при исключении утечёт.

Правила catch

  • Полиморфные типы и крупные объекты ловите по const T&, чтобы не копировать и не «срезать» объект.
  • Порядок блоков важен: сначала частные типы, потом более общие. catch (...) перехватывает всё и ставится последним.
  • Не бросайте исключения из деструктора: во время раскрутки второе исключение завершит программу.
Функцию, которая точно не бросает исключений, можно пометить noexcept. Это подсказка компилятору и контракт: если исключение всё же вылетит, программа завершится.
Исключения — для редких ошибок, а не для обычного управления потоком («нашли элемент — бросили»). В конструкторе исключение — нормальный способ сказать «объект создать не удалось»; частично созданный объект при этом уничтожается корректно, если каждый член сам владеет своим ресурсом.

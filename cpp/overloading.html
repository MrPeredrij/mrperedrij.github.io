Перегрузка функций и аргументы по умолчанию

В C++ несколько функций могут иметь одно имя, если различаются числом или типами параметров. Компилятор выбирает подходящую версию по аргументам вызова. Только типом возвращаемого значения перегрузить функцию нельзя.

Аргументы по умолчанию

Значения по умолчанию указывают в объявлении, справа налево: нельзя задать значение для параметра, если у следующего его нет. В определении функции их обычно не повторяют.

Как компилятор выбирает перегрузку

  1. Точное совпадение типов (включая T& и const T& по правилам привязки).
  2. Стандартные преобразования (продвижение short к int, int к double и т. д.).
  3. Пользовательские преобразования (конструкторы и операторы преобразования).

Если две кандидатуры одинаково хороши, программа не компилируется: вызов неоднозначен. Так бывает, когда перегрузка пересекается с аргументами по умолчанию.

Не задавайте разным перегрузкам разный смысл «на грани»: draw(int) и draw(bool) легко вызвать случайно, потому что true превращается в int. Лучше разные имена или сильно различные типы.
Перегрузка и шаблоны работают вместе: если есть шаблон и обычная функция, компилятор предпочитает более конкретную обычную функцию при точном совпадении.

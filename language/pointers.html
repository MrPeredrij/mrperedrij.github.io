Указатели

Указатель хранит адрес объекта. Оператор & берёт адрес, оператор * обращается к объекту по адресу (разыменование).

Адресная арифметика

Прибавление целого n к указателю сдвигает его на n элементов, а не байт. Выражение a[i] по определению эквивалентно *(a + i). Разность двух указателей на один массив имеет тип ptrdiff_t.

Указатели и const

ОбъявлениеЧто нельзя менять
const int *pзначение по адресу (*p = 1 — ошибка)
int *const pсам указатель (p++ — ошибка)
const int *const pни то, ни другое

Правило чтения: объявление читается справа налево — int *const p означает «p — константный указатель на int».

void * — обобщённый указатель

void * может хранить адрес объекта любого типа и неявно преобразуется в любой указатель на объект. Разыменовать void * нельзя — сначала его приводят к конкретному типу.

Массив указателей на строки

Типичные ошибки: разыменование NULL или неинициализированного указателя, использование указателя на локальную переменную после выхода из функции, обращение к памяти после free. Найти их помогает -fsanitize=address.

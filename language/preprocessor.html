Препроцессор

Препроцессор обрабатывает текст программы до компиляции. Его директивы начинаются с #. Результат можно посмотреть командой gcc -E file.c.

ДирективаНазначение
#include <file.h>вставить системный заголовок
#include "file.h"вставить заголовок проекта (поиск сначала в каталоге файла)
#define, #undefопределить и отменить макрос
#if, #ifdef, #ifndef, #elif, #else, #endifусловная компиляция
#errorостановить компиляцию с сообщением
#pragmaуказание компилятору (например, #pragma once — нестандартное, но распространённое)
#lineизменить номер строки и имя файла в диагностике

Макросы

Параметры и всё тело макроса берут в скобки, иначе приоритет операторов даст неожиданный результат. Аргумент макроса может вычисляться несколько раз — не передавайте выражения с побочными эффектами.

Условная компиляция

Значение макроса можно задать при компиляции: gcc -DDEBUG=1 main.c.

_Generic и _Static_assert (C11)

_Generic выбирает выражение по типу аргумента во время компиляции — так можно написать «перегруженный» макрос. _Static_assert проверяет условие на этапе компиляции.

Предопределённые макросы

  • __FILE__, __LINE__ — имя файла и номер строки;
  • __DATE__, __TIME__ — дата и время компиляции;
  • __STDC_VERSION__ — версия стандарта: 201112L для C11, 201710L для C17;
  • __func__ — не макрос, а предопределённый идентификатор с именем текущей функции (C99).

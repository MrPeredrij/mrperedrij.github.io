Динамическая память

Объекты в C живут в одной из трёх областей:

  • статическая — глобальные и static-переменные, живут всё время работы программы;
  • автоматическая (стек) — локальные переменные, уничтожаются при выходе из блока;
  • динамическая (куча) — память, выделенная функциями из <stdlib.h>; живёт до вызова free.
ФункцияДействие
malloc(size)выделить size байт, содержимое не определено
calloc(n, size)выделить n * size байт, заполненных нулями
realloc(p, size)изменить размер блока; может переместить его
free(p)освободить блок; free(NULL) безопасен
aligned_alloc(al, size)выделить память с выравниванием al (C11)

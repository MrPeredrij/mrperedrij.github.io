Простые числа

Натуральное число n > 1 называется простым, если делится только на 1 и на себя. Остальные числа больше 1 — составные. 1 простым не считают.

Перебор делителей

Достаточно искать делитель от 2 до √n: если меньшего делителя нет, большего тоже не будет (он шёл бы в паре с меньшим). Сложность проверки одного числа — O(√n). Для редких проверок этого хватает; чтобы получить все простые до большого n, лучше решето.

Цикл идёт только по нечётным d после отдельной проверки на 2. Условие d * d <= n сравнивает целые и не требует <math.h>. Для больших n умножение d * d должно помещаться в тип: берите достаточно широкий целый тип либо сравнивайте d <= n / d.

Решето Эратосфена

Чтобы найти все простые до n, заводим массив «возможно простое» и последовательно вычёркиваем кратные очередного простого, начиная с квадрата (меньшие кратные уже вычеркнуты раньше). Время — около O(n log log n), память — O(n).

memset(..., 1, ...) заполняет байты значением 1, что для bool (и для _Bool) подходит как «истина». Не используйте этот приём для массива int: байты 0x01010101 — это не единица в каждом элементе.

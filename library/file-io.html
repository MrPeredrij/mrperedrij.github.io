Работа с файлами

Файл открывается функцией fopen, которая возвращает указатель на FILE или NULL при ошибке. Стандартные потоки stdin, stdout и stderr открыты автоматически.

РежимОписание
"r"чтение; файл должен существовать
"w"запись; файл создаётся или обрезается до нуля
"a"дозапись в конец
"r+", "w+", "a+"чтение и запись
"wx"создать новый файл, ошибка если он уже есть (C11)
суффикс bдвоичный режим (важно в Windows: "rb", "wb")

Текстовые файлы

Двоичные файлы: fwrite и fread

Двоичный формат, записанный fwrite из структуры, зависит от платформы: от порядка байтов, размера типов и выравнивания. Для обмена между разными системами используйте текстовый формат или явную сериализацию по байтам.

Посимвольная обработка: подсчёт строк, слов и байтов

Обработка ошибок

  • perror(msg) печатает msg и описание текущего errno в stderr;
  • strerror(errno) возвращает текст ошибки;
  • feof(f) и ferror(f) позволяют отличить конец файла от ошибки чтения;
  • fflush(f) принудительно записывает буфер потока.
